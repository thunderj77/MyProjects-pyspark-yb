## 📌 Описание проекта

Сервис «Яндекс Книги» предоставляет пользователям доступ к текстовым книгам и аудиокнигам (по подписке) через мобильные приложения (iOS/Android), веб-версию и умные колонки «Станция». Задача – проанализировать поведение пользователей, выявить ключевые паттерны потребления и предложить точечные улучшения продукта.

### Ключевые объекты анализа

| Категория | Детали |
|-----------|--------|
| **Типы контента** | Аудиокниги, текстовые книги, комиксы |
| **Платформы доступа** | Мобильное приложение, веб, умная колонка «Станция» |
| **Временные паттерны** | Будни vs выходные |
| **Целевая аудитория** | Взрослый контент vs детский контент |

### Основные вопросы исследования

1. Какой тип контента (аудио/текст) доминирует по времени и частоте?
2. Какие платформы приносят основное время потребления?
3. Отличается ли поведение в будни и выходные?
4. Как потребляют взрослый и детский контент?
5. Какие бизнес-рекомендации следуют из полученных инсайтов?

## 🔍 Ход работы

### 1. Загрузка и подготовка данных
- Загружены две таблицы: `audition.csv` (1 002 896 сессий) и `content.csv` (31 668 объектов контента)
- Схемы данных заданы явно через `StructType` для контроля типов на входе
- Выполнена очистка: отобраны релевантные колонки, удалены дубликаты

### 2. Трансформации и feature engineering
- Часы переведены в целые минуты для наглядности
- Добавлен флаг выходного дня на основе даты события
- Создана кэшированная таблица для многократных агрегаций

### 3. Соединение таблиц (JOIN)
- Таблицы объединены по идентификатору контента
- Использована оптимизация broadcast для малой таблицы-справочника
- Проведена валидация: дубликаты и пропуски отсутствуют

### 4. Аналитические агрегации
- Построены группировки по платформам, типам контента, возрасту, дням недели
- Рассчитаны: общее время, количество сессий, средняя длительность, уникальные пользователи

## 📊 Ключевые результаты

### Распределение по типам контента

| Тип контента | Доля сессий | Средняя длительность |
|--------------|-------------|----------------------|
| Аудиокниги | 89% | 22 мин |
| Текстовые книги | 10% | 48 мин |
| Комиксы | 1% | 25 мин |

### Топ платформ по общему времени

| Платформа | Общее время (часов) | Средняя сессия (часов) |
|-----------|--------------------|------------------------|
| Букмейт Android | 147 814 | 1.16 |
| Станция | 125 219 | 0.18 |
| Букмейт iOS | 63 945 | 0.83 |
| Музыка Android | 44 183 | 0.84 |

### Взрослый vs детский контент

| Показатель | Взрослый контент | Детский контент |
|------------|------------------|------------------|
| Доля времени | 81% | 19% |
| Средняя сессия | 53 мин | 7.6 мин |
| Зависимость от дня недели | низкая | низкая |

### Будни vs выходные
- Будни – в **2.7 раза больше минут** потребления, чем выходные
- Вероятный сценарий: поездки на работу/с работы, фоновое прослушивание

## 💡 Выводы и рекомендации

### Основные инсайты

- **Аудиокниги – драйвер частоты** (89% сессий), но текстовые книги дают самое глубокое погружение (48 мин)
- **Взрослая аудитория** делает 80%+ времени сервиса, сессии в 7 раз длиннее детских
- **Букмейт Android** – ключевая платформа по времени и средней сессии
- **Станция** – лидер по частоте включений, но короткие сессии
- **Будни** – пик активности (транспортные сценарии)

### Рекомендации по продукту

| Приоритет | Рекомендация | Ожидаемый эффект |
|-----------|--------------|------------------|
| High | Увеличить вес аудиокниг в рекомендательных моделях | Рост вовлечённости |
| High | Улучшить синхронизацию «Станция ↔ Android» | Рост глубины сессий на колонке |
| Medium | A/B-тест: пуш с аудиокнигой в 18:00 (будни) для Android | Увеличение удержания |
| Medium | Для детского контента – короткие форматы и серийность | Удержание юной аудитории |
| Low | Исследовать точки входа в книги внутри Яндекс Музыки iOS | Выравнивание вовлечённости |

### Ближайшие шаги

1. Запустить A/B-тест: персонализированные push-уведомления с аудиокнигой в 18:00 по будням (Android)
2. Добавить на умную колонку функцию «продолжи с телефона»
3. Проанализировать низкую вовлечённость в книгах в приложении Яндекс Музыка iOS
4. Проверить гипотезу о коротких сессиях в «Станции» из-за отсутствия удобного продолжения
